git diff - построчная разница между двумя коммитами

git show - один коммит целиком

git log - список истории коммитов

log -S - нашел коммиты, в которых появились новые определения функции

blame - по каждой строке файла видно, какой коммит ее добавил

git restore - вернуть файл к состоянию последнего коммита

git restore --source=… - взять содержимое файла указанного комита и положить в рабочую папку. в историю ничего не записывается

правки безвозвратно теряются

git revert - создает новый коммит, который отменяет изменения указанного 

git reset --hard - перемещает указатель ветки назад и стирает все коммиты после указанного из текущей ветки

безопаснее revert так как он доавляет новый коммит поверх
