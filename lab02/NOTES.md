Рабочая папка — файлы проекта, которые я редактирую
Индекс — промежуточная область, куда я добавляю изменения через git add
Коммит -сохраненные изменения, зафиксированный снимок истории
git — инструмент контроля версий установленный локально на компьютере
Github — облачный сервис для хранения репозиториев, нужен для совместной работы и публикации
«Использованные команды»:
git status - показывает состояние на какой я ветке, какие файлы изменены, какие в индексе
git diff - сравнивае рабочую папку с индексом
git diff --staged - сравнивет индекс с последним коммитом
раздел «Ветки»:
Ветка - подвижный указатель на коммит. позволяет вести параллельную работу не затрагивая основную линию
новый комит создает новую точку в текущей ветке
слияние - объединяет изменение одной ветки в другую . создается merge-commit в котором сохраняется история двух веток
